This a snake game created using python. The snake games conists of 3 different files namely: The food.py, the scoreboard.py and the snake .py making use of the OOP i have been able to use different files to represent different aspects for the game. For example the food.py is the object file for controlling how the food(which is a red dot) appear on the screen randomly and the snake.py is the object file used in creating the snake object describing the directions the snake can go and how it responds to keyboard input, and the Scoardboar.py is the object file for storing the highest score in each game played
